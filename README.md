# ✦ ละมุนรส (Lamunros Thai Cuisine)
> เว็บไซต์ร้านอาหารไทยร่วมสมัย ดีไซน์มินิมอลสบายตา พัฒนาด้วย **React + TypeScript (TSX) + Tailwind CSS** ขับเคลื่อนด้วย Vite

---

## 🛠️ เทคโนโลยีที่ใช้ในการพัฒนา
- **Language & Runtime:** TypeScript (Strict Mode)
- **UI Framework:** React 19 (TSX Functional Components with Hooks)
- **Styling:** Tailwind CSS v4 (Modern Utility-first CSS + Warm Earth-Tone Palette)
- **Icons:** Lucide React
- **Build Tool & Bundler:** Vite 8 (Ultra-fast HMR)

---

## 📋 ข้อมูลสำคัญและหมวดหมู่อาหาร
เว็บไซต์แบ่งหมวดหมู่อาหารตามสำรับไทยแท้อย่างครบถ้วน:
1. **🍲 กับข้าว (Main Dishes):** เช่น ต้มยำกุ้งแม่น้ำน้ำข้นโบราณ, แกงเขียวหวานเนื้อริบอายพริกขี้หนูสวน, ปลากะพงทอดน้ำปลาหอม, มัสมั่นน่องเป็ดกงฟีต์, ผัดกะเพราเนื้อวากิวสับไข่ดาวเป็ดลาวา, ผัดไทยห่อไข่โบราณ ฯลฯ
2. **🍵 เครื่องดื่ม (Beverages):** เช่น ชาไทยการันต์สกัดเย็นนมสดฮอกไกโด, น้ำมะพร้าวน้ำหอมอัญชันเกล็ดหิมะ, ชามะนาวน้ำผึ้งป่าเดือนห้า, น้ำกระเจี๊ยบพุทราจีนสมุนไพรเตาถ่าน, กาแฟโบราณคาราเมลตาลโตนด ฯลฯ
3. **🍨 ขนมหนมหวาน (Desserts):** เช่น ข้าวเหนียวมะม่วงอกร่องทองอบควันเทียน, บัวลอยเผือกกล้วยบวชชีไข่หวาน, ทับทิมกรอบชาววังไอศกรีมกะทิรมควัน, ขนมถ้วยตะไลใบเตยสดหน้าเยิ้ม, ลอดช่องสิงคโปร์น้ำเชื่อมตาลโตนด ฯลฯ

## 🎨 สไตล์การออกแบบ (Minimal & Eye-Comfort Tailwind CSS)
- **Warm Earth-Tone Palette:** 
  - พื้นหลังสีครีมอุ่นนวลตา (`#FAF8F5`, `#F4EFEA`)
  - โทนส้มอิฐเผาไทยโบราณ (`#C85A32`, `#B24B25`)
  - โทนเขียวสมุนไพรไทย (`#4A6B53`)
  - โทนสีทองและอำพัน (`#C48E25`, `#FBF4E6`)
  - ตัวหนังสือสีน้ำตาลเอสเปรสโซเข้ม ไม่ตัดดำสนิท ลดความล้าของสายตา (`#2A2421`)
- **Typography:** ผสานฟอนต์หัวเรื่องแบบ Serif สง่างาม (*Noto Serif Thai*) และฟอนต์อ่านง่าย (*Sarabun* / *Plus Jakarta Sans*)
- **Responsive Layout:** ปรับแต่งการจัดวางแบบ Responsive Fluid Grid แสดงผลสวยงามบนสมาร์ตโฟน, แท็บเล็ต, แล็ปท็อป และหน้าจอขนาดใหญ่

## 🧩 โครงสร้างโมดูลาร์ (TSX Components)
- `src/types.ts`: กำหนด Type และ Interface ทั้งหมด (`Category`, `MenuItem`, `CartItem`, `ReservationData`)
- `src/components/Navbar.tsx`: แถบนำทางด้านบนแบบ Glassmorphism พร้อมแจ้งสถานะโต๊ะและ Badge สำรับอาหาร
- `src/components/Hero.tsx`: แบนเนอร์หน้าแรกแนะนำเมนูเอก ตอกย้ำความประณีตของสูตรโบราณ
- `src/components/CategoryTabs.tsx`: แท็บเลือกหมวดหมู่ 4 หมวด, ช่องค้นหาเรียลไทม์ และปุ่มตัวกรอง (เชฟแนะนำ, ยอดนิยม, เผ็ดน้อย)
- `src/components/FoodCard.tsx`: การ์ดเมนูอาหารพร้อมระดับความเผ็ด แคลอรี ป้ายแนะนำ และปุ่มสั่งอาหาร
- `src/components/MenuGrid.tsx`: ตารางเมนูจัดกลุ่มตามประเภทอัตโนมัติพร้อมหน้ารองรับเมื่อค้นหาไม่พบ
- `src/components/FoodDetailModal.tsx`: หน้าต่างปรับระดับความเผ็ด ความหวาน และโน้ตถึงก้นครัว
- `src/components/OrderDrawer.tsx`: ถาดสำรับอาหาร (Cart Drawer) เลือกทานที่ร้าน (โต๊ะ 08) หรือสั่งกลับบ้าน พร้อมคำนวณ VAT 7%
- `src/components/ReservationModal.tsx`: ระบบสำรองโต๊ะล่วงหน้า พร้อมเลือกโซนที่นั่ง
- `src/components/Footer.tsx`: ท้ายเว็บมินิมอล แสดงเวลาเปิด-ปิด และข้อมูลการติดต่อ
- `src/components/Toast.tsx`: แจ้งเตือนสถานะเมื่อเพิ่มอาหารหรือทำรายการสำเร็จ

## 🚀 วิธีการเปิดใช้งาน
1. **เริ่มระบบผ่านไฟล์คลิกเดียว:**
   ดับเบิลคลิกที่ไฟล์ **`start.bat`**
2. **หรือใช้คำสั่งผ่าน Terminal:**
   ```bash
   npm run dev
   ```
   ระบบจะเปิดเซิร์ฟเวอร์และเปิดเบราว์เซอร์ให้อัตโนมัติที่ `http://localhost:3000`
